# ══════════════════════════════════════════════════════════════════════
# LANGKAH INSTALL DI RASPBERRY PI 4  (jalankan berurutan di terminal Pi)
# ══════════════════════════════════════════════════════════════════════
#
# 1) Update sistem + dependency C untuk OpenCV / pygame / ffmpeg:
#    sudo apt update && sudo apt upgrade -y
#    sudo apt install -y python3-venv python3-pip \
#         libgl1 libglib2.0-0 libsm6 libxext6 libxrender1 libgomp1 \
#         ffmpeg libatlas-base-dev libopenblas-dev \
#         libsdl2-2.0-0 libsdl2-mixer-2.0-0 libportaudio2
#
# 2) Buat & aktifkan virtual environment (Python 3.11 bawaan Bookworm):
#    python3 -m venv ~/parking-env
#    source ~/parking-env/bin/activate
#    pip install --upgrade pip wheel setuptools
#
# 3) Aktifkan piwheels supaya opencv/numpy dapat wheel prebuilt ARM
#    (biasanya sudah aktif di Pi OS). Cek/isi /etc/pip.conf:
#    [global]
#    extra-index-url=https://www.piwheels.org/simple
#
# 4) Install semua dependency:
#    pip install -r requirements-rpi.txt
#
#    Kalau torch gagal, install manual dulu lalu ulangi perintah di atas:
#    pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#
# 5) (Optimasi) Export model YOLO ke NCNN sekali saja di Pi, lalu pakai
#    hasilnya di kode (jauh lebih cepat daripada .pt di CPU ARM):
#    yolo export model=best.pt     format=ncnn
#    yolo export model=triangle.pt format=ncnn
#    # menghasilkan folder best_ncnn_model/ dan triangle_ncnn_model/
#    # Alternatif ONNX:  yolo export model=best.pt format=onnx
#
# 6) Jalankan backend:
#    uvicorn backend.main:app --host 0.0.0.0 --port 8000
#
# ── CATATAN KINERJA ───────────────────────────────────────────────────
# • Pi 4 CPU-only: YOLOv8n ~ beberapa FPS. Pakai model *n* (nano) + NCNN.
# • RAM 4 GB cukup untuk 1 model; hindari jalankan 2 model berat sekaligus.
# • Tambah swap kalau OOM saat install/inferensi:
#     sudo dphys-swapfile swapoff
#     sudo sed -i 's/^CONF_SWAPSIZE=.*/CONF_SWAPSIZE=2048/' /etc/dphys-swapfile
#     sudo dphys-swapfile setup && sudo dphys-swapfile swapon
# • Turunkan resolusi input & set imgsz kecil (mis. 320/416) untuk FPS lebih baik.
# • pygame tanpa audio device: alert TTS akan di-skip otomatis (aman).
# ══════════════════════════════════════════════════════════════════════
